Model Builder

อ่าน static C3D แล้วสร้าง Visual3D model template (.mdh) สำหรับ lower body 16 markers จับคู่ label กับ motion file และสร้าง pipeline (.v3s)

เครื่องมือเดิม: ตรวจ .mdh, อ่าน build log, pipeline รุ่นเดิม

1 Static C3D

กำลังแสดงไฟล์ตัวอย่าง (static ของ Motive วันที่ 10 พ.ย. 2026) เลือกไฟล์ของพี่เพื่อแทนที่

ค่าเฉลี่ยตำแหน่ง marker ในช่วงเฟรมนี้ใช้คำนวณค่าคาดหวังเท่านั้น ไม่ได้เขียนลงใน mdh

1b Motion C3D (ตัวอย่าง trial)

แอปจะจับคู่ label ของ motion กับ static ให้เอง ตรวจ gap, ทิศ R/L และสร้างไฟล์ motion สำเนาที่เปลี่ยนชื่อ marker ให้ตรงกับ mdh (ไฟล์ต้นฉบับไม่ถูกแก้) ไฟล์ถูกอ่านในเบราว์เซอร์ ไม่ถูกอัปโหลดไปไหน
