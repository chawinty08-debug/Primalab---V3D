ต้นแบบเพื่อการเรียนรู้: ไฟล์ที่สร้างเป็น ร่าง ยังไม่ได้ทดสอบกับ Visual3D ของคุณ ตรวจ build log ทุกครั้งก่อนใช้งานจริง ค่าที่ติด <<MEASURE>> ต้องใส่ค่าจริงของผู้ถูกทดสอบ ข้อมูลทั้งหมดประมวลผลในเบราว์เซอร์ของคุณ ไม่มีการอัปโหลด

ไฟล์ C3D (static) และข้อมูลผู้ถูกทดสอบ

แม่แบบ: IOR full body จากตัวอย่าง HAS-Motion (pelvis + trunk + ขา + เท้า ไม่มีแขน/ศีรษะ) · ส่วน build ใน Visual3D ยังไม่ทดสอบ

    เลือก segment

    การตัด segment จะตัด landmark/metric ที่ใช้เฉพาะ segment นั้นออกด้วย และตัด segment อื่นที่ต้องพึ่งมัน (แจ้งใน “ข้อความ”)

    ผลลัพธ์ .mdh

      ค่าคาดหวังเพื่อเทียบกับ build log (หน่วย m)

        ข้อมูลผู้ถูกทดสอบและ marker

        แม่แบบ: Conventional Lower (16) · ส่วน build ผ่านแล้วในโปรเจกต์ (v4) · มุม/Cardan ยังไม่ยืนยัน

        เว้นว่าง = ใช้ค่า placeholder ของแม่แบบ (จะถูกเตือนว่ายังไม่ใช่ค่าจริง) ความกว้างข้อวัดด้วย caliper แบบผิวถึงผิว

        ชื่อ marker ใน C3D ของคุณ (ถ้าต่างจากค่าเริ่มต้น)

        ใช้ชื่อตามที่ปรากฏใน C3D จริง ไม่ใช่ชื่อจากหน้า doc ของ marker set ไม่ต้องใส่ prefix ในช่องเหล่านี้

        ผลลัพธ์ .mdh

          ลำดับคำสั่ง

          ตัวอย่างใน wiki ใช้ 6 Hz เป็นแค่ตัวอย่าง ไม่ใช่ค่าแนะนำ ให้เลือกตามลักษณะงาน/การตรวจสัญญาณ · หลักคิดการ filter ↗

          Link model based (เลือกชนิด × joint)

          Moment/force/power ต้องมี force platform ใน C3D และ force ถูก assign ให้ foot (อัตโนมัติจากระยะ COFP) · ยังไม่ได้ทดสอบ

          Joints

          ชื่อ segment เป็นรหัสมาตรฐาน (RHE, RAR, RFA, RHA ฯลฯ) ต้องมีในโมเดลของคุณ · template IOR ในแท็บ 1 มี pelvis/trunk/ขา/เท้าเท่านั้น (ยังไม่มีแขน/ศีรษะ) · joint อื่นให้เพิ่มเองด้านล่าง

          ที่มาของลำดับ Cardan: โมดูล 6 ข้อกำหนดของมุม ↗

          ผลลัพธ์ .v3s

            วาง .mdh ที่ต้องการตรวจ

            ตรวจ: จำนวนรายการ +, ชื่อซ้ำ, target ที่ไม่มีใน C3D, landmark/metric ที่อ้างแต่ไม่ได้นิยาม, tracking < 3 จุด

            ผลการตรวจ

              วาง build log

              กฎที่มีมาจากข้อผิดพลาดที่เคยพบในโปรเจกต์นี้และ wiki ไม่ครอบคลุมทุกกรณี บรรทัดที่ไม่มีกฎจะแสดงเป็น “ยังไม่มีคำอธิบาย”

              ผลวิเคราะห์

                Visual3D เป็นผลิตภัณฑ์/เครื่องหมายของเจ้าของผลิตภัณฑ์ เครื่องมือนี้ไม่ใช่เครื่องมือทางการและไม่ได้เกี่ยวข้องกับผู้ผลิต · syntax อ้างอิง wiki.has-motion.com และข้อมูลการ build จริงในโปรเจกต์ · ใช้เพื่อการเรียนรู้
